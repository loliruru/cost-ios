# Cost iOS 产品规格

状态：移植规格，业务尚未实现。审计基线为 Android HEAD `9f461eb4efb25aa9e64bb7ec1cc9ba50d71f602b`、Phase 20、Room v10；日期 2026-11-15（Asia/Singapore）。

## 产品与范围

Cost 是长期自用、隐私优先、offline-first 的原生记账工具：快速记录日常收支，查看消费趋势与分类组成，精确保留跨币种历史。iOS 使用 SwiftUI 与 Apple 导航规范，业务来自 Android 当前文档、源码与测试，不复制 Material UI。无广告、强制注册、银行自动同步、多人账本、云端异常分析或交易终端。

以下描述目标行为；实际交付只以[实施计划](IMPLEMENTATION_PLAN.md)为准。Android 功能完成不代表 iOS 已实现。

## 账单与基础资料

- 收入/支出金额为正数；每笔保存原币、scale、分类（最多两级）、账户、发生日期/时区、备注、多标签、来源、创建/更新时间及冻结换算快照。
- 主路径为金额 → 分类 → 保存；账户、时间、备注、标签、币种和估值按需展开。SwiftUI Sheet/NavigationStack 提供新增、详情、编辑；输入校验失败或联网失败保留草稿。
- 默认列表按发生时间倒序，有界加载/分页；Android 当前最近列表上限为 200，不能把全库加载当作默认查询。支持按自然日分组、搜索及筛选。
- 普通删除是可恢复软删除；列表、统计、资金计算排除已删除记录，撤销/恢复保留稳定 ID 和快照。重复保存使用 request key 幂等。
- 分类最多两级、父子收支类型一致；停用父分类同时停用直接子分类，恢复子项先恢复父项。历史仍按稳定 ID 读取当前名称与视觉。重命名需提示历史显示影响；新增不得改写其他资料。
- 已停用分类经二次确认，只有无任何子分类及全部历史引用时才能永久删除；软删除账单、停用模板、暂停规则、撤销转账和异常反馈均保护引用。检查与删除必须在同一事务完成。
- 账户支持排序、默认项、可选币种与停用；最多一个默认账户，停用默认账户后允许没有默认项。账户币种不隐式限制普通账单原币种。
- 标签采用 NFKC、Unicode 空白折叠、去首尾空白、与 Locale.ROOT 等效的小写归一化，规范名唯一。新增同名复用稳定 ID，停用项恢复且保留旧名称/颜色；编辑碰撞报错。只允许确认删除已停用标签：原子移除其账单/模板/循环关联及标签，保留宿主记录和金额。
- 分类/账户可选内置图标、单个 emoji sequence 或私有受管图片；背景独立可选并保存顶部/居中/底部焦点。系统选择器导入有界、去元数据的静态副本，损坏/缺失回退，停用不解除历史引用。iOS 系统操作图标使用 SF Symbols；Android 个人资料及图标映射不自动成为新账本 seed。

## 可选账户资金

这是 Android v10 已有业务，归入 iOS Phase 3，不从移植中丢弃：

- 每账户追踪默认关闭，未设置不等于零。开启、关闭、校准均追加 revision，以保存时点为新起点；不重复扣减此前旧账，再开启需填写新的当前金额。
- 可用金额 = 期初 + 起点后收入 − 支出 + 转入本金 − 转出本金。投入成本 = 期初 + 转入本金 − 转出本金；不随普通费用、收益或市场价格自动重估。
- 本金转账独立于收支，只支持同一已启用法币。投资提回分别填本金及带符号损益，到账不得为负；损益只限投资成本 → 可用金额方向，独立手续费另记支出。
- 转账与关联损益账单原子保存、编辑、软删除、恢复；request key 防重、expectedUpdatedAt 防并发覆盖。受管损益不得从普通账单入口独立修改或删除。
- 仅计算设置起点之后事件；同一毫秒按创建时刻区分。普通外币先匹配原币，否则使用相同币种的冻结本位币，两者均不匹配则明确待核对。使用精确派生总额，不保存漂移累计余额。
- 默认 seed 不包含真实金额、个人账户 ID 或演示数值。完整迁移使用完整备份，CSV 不携带资金关系。

## 快捷模板

模板保存名称、图标、金额/币种/收支、分类、账户、备注、标签、用户排序、使用次数和最近使用时间，不预存当次 FX 快照。仅接受 Fiat。

一键记账使用当前时间解析估值，唯一 request key 的账单插入与使用统计更新同事务；重复点击/重试不重复写入或增加次数。撤销在同一事务软删除该笔并回退对应次数和最近使用时间。编辑后保存只创建账单，不回写模板。排序依次为 sortOrder 升序、usageCount 降序、lastUsedAt 降序、id 升序。停用/恢复保留历史；确认删除只移除模板和关联，不删除已生成账单或其来源标识。

## 周期记账

规则和模板生命周期独立。频率为每天、工作日（周一至周五，不推断节假日）、指定星期、月、年及 N 日/周/月/年；保存起止日期、IANA zone、计划本地时间、月底 LAST_DAY/SKIP、补记 CREATE_MISSED/SKIP_MISSED。

同一规则与计划 instant 至多生成一次。transaction、execution、规则游标原子推进；账单发生时间为计划时间，创建时间为实际执行时间。暂停不生成；恢复按用户明确选择的补记策略执行。确认删除规则只停止未来调度并移除执行状态，保留历史交易。

iOS 后台刷新尽力执行，不保证准点；前台启动/恢复时补处理按策略到期的 occurrence，通知仅提醒。当天 occurrence 使用 fresh latest，过去日期使用计划业务日 historical；失败保留可重试/跳过的状态，不写半成品。DST 精确语义见[数据模型](DATA_MODEL.md)。

## 多币种与估值

Currency 为 seed data；11 个 Fiat 默认启用，USDT/USDC/BTC/ETH metadata 默认停用；完整 scale 见数据模型。本位币默认 CNY，仅接受启用 Fiat。改变本位币需确认，只影响之后新草稿，历史与已打开草稿不重估。不同历史本位币不可直接相加。

Fiat：实际扣款金额 > 手工率；自动路径当天只直接接受 fresh latest，过去日期要求对应 historical。current/cached fallback 必须明确确认，并冻结不同 valuation method。Twelve Data Forex v2 的 latest freshness 以 provider timestamp + 5 分钟计算，不能被新 fetchedAt 延长；展示来源、数据时间、抓取时间和过期状态，不承诺零延迟。

Crypto（iOS Phase 7）：显式启用后支持基础收支，实际结算金额 > 实际单价 > 用户明确选择的市场参考价。使用独立 Provider、类型与缓存，稳定币不假定 1:1；过去日期输入当时单价或结算额。模板、周期与本位币仍限 Fiat，无仓位、自动交易或后台行情轮询。

密钥由用户在 Settings 输入并保存 Keychain；未配置返回 notConfigured，不联网，保留手工估值。禁止沿用 Android 编译注入的个人凭据。

## 统计与异常

- 使用冻结 converted base amount，按本位币分组/筛选。7/30/90 天包含今天；自定义闭区间在查询时转换为半开边界。零账单日期补零。
- 日均分母包含全部自然日；月/季/年均按覆盖日历周期，首尾不完整须返回 partial 标记。比较采用等长已过时段；零基准返回绝对变化及百分比不可用，数据不足返回明确状态。
- 展示日趋势、分类组成/排名、收支对比、环比/同比；SQL 聚合和索引支持，不能读取全库后计算。
- 异常为本地、可解释的单笔/单日/叶分类检测。候选 7/30 天，基线严格在之前，优先 30 天、不足扩展 90 天；至少 5 个有效单笔/活跃日。循环支出从候选和基线排除，零消费日保留，活跃中位数避免稀疏消费误判。
- 稳健波动 = max(1.4826×MAD, IQR/1.349)；低/标准/高波动倍数 6/4/3，金额比例门槛 3/2.5/2，阈值取中位数加波动倍数、活跃中位数比例、均值比例三者最大值。仅严格超阈值报告。精确算法与样本上限按 Android 测试移植。
- 忽略本次抑制事件；标记相似正常抑制同类型、叶分类、本位币、金额 ±20% 的事件。反馈持久化，可清除；灵敏度与开关为设置。样本过多/不足明确提示，最多展示最近 30 项并注明总数；无后台扫描、联网或异常系统通知。

## 数据携带与隐私

CSV 为版本化 UTF-8 RFC 4180，固定头和 context_json，所有非 null 单元有可逆单引号前缀，null 为 `\N`；包含软删除交易及引用元数据。只接受原始 Cost 格式，ID/内容一致跳过、冲突整次回滚，不覆盖现有交易。图片回退内置、emoji 保留；不携带模板、规则、资金起点、本金转账及受管损益关系。

完整备份含 COSTBK01 envelope、ZIP 内的 SQLite、七项偏好、manifest 和受管图片，保留全部 17 张账本表。恢复先私有 staging、迁移/精确字段/外键/hash 校验，预览后用户明确确认替换；一次事务提交账本与设置 outbox，失败不破坏原账本，提交后设置中断在启动时重放。格式及跨平台边界见数据模型与决策。

不自动上传、不复制整个应用目录、不导出 Keychain、Apple ID、原照片/EXIF、配对文件或调度系统内部库。可选密码加密采用 Android 相同参数，密码不持久化或提供找回。系统文件选择器负责主动导入/导出，失败不得报告成功。

## 质量与验收

原生导航与 TabView、系统输入、Light/Dark、Dynamic Type、VoiceOver 图表摘要、Reduce Motion/Transparency、键盘及安全区适配。审美由用户真机判断，业务、精度、数据一致性与客观可访问性由自动化验证。每阶段完成提交后停止，Phase 1 green 前不开始业务实现。
