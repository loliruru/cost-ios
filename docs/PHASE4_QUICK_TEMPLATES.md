# Phase 4 快捷模板

## 交付范围

- 「模板」标签页支持新增、编辑、排序、停用、恢复与确认删除。排序依次为用户顺序升序、有效一键使用次数降序、最近使用时间降序、稳定 ID 升序。模板可保存已启用法币，金额沿用精确 Money 解析。
- 本币一键记账冻结发生时间、时区、业务日期和 identity 估值。请求键与账单唯一约束防止重复写入，同一事务更新使用次数及最近使用时间。
- 模板页「撤销记账」与账单页软删除一键生成的账单，都在同一事务回退使用统计。恢复该账单时也恢复统计。最近使用时间取仍有效的一键账单的创建时间，连续撤销无需依赖内存快照。普通账单及编辑后保存的模板账单不纳入一键统计。
- 编辑后记账复用录入页，保留模板来源，保存只写账单。外币模板缺少完整估值时直接进入录入草稿，关闭后可以恢复。在线估值仍在 Phase 7。
- 已停用的模板或其分类、账户、标签、币种会明确拦截新记账。删除模板只清理模板和标签关联，已有账单及来源 ID 保留。

原有 v1 模板表与账单表可承担本阶段数据。通过保留的 `quick-template-use:` 请求键前缀标记一键路径，编辑后记账使用普通唯一请求键。没有新增迁移、seed 或依赖。Android 参考为 `ManageQuickTemplatesUseCase`、`QuickTemplateDao`、`RoomTransactionRepository` 的模板原子写入与撤销、以及原有 schema v10。

## 真机验收

1. 打开「模板」，新增 CNY 支出模板「验收午餐」，填写金额 12.34、分类和账户。点「一键记账」，确认账单和一次使用记录。立即再次双击，验证一次手势不会写两笔。
2. 回到模板页点「撤销记账」。账单从活动列表消失，使用次数和最近使用时间回退。恢复该账单后，统计随之恢复。
3. 点「编辑后记账」，将金额改为 20.01 并保存。应生成新的 20.01 账单，原模板的 12.34 和使用统计保持原值。
4. 新建 USD 模板并点「一键记账」。录入页应预填金额和币种并解释估值尚未开放。关闭后通过同一模板重新打开，应恢复草稿。
5. 停用并恢复模板，再确认删除。检查历史账单仍存在。对比浅色、深色及最大 Dynamic Type 下模板页的名称、金额与两项操作是否清楚可达。
